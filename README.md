# Roadmap Costa Este

App del viaje Mendoza ↔ Costa Este (noviembre 2026). Es la migración del canvas de Cursor a un proyecto Next.js, con [Cobe](https://cobe.vercel.app/) para el globo.

## Local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

El itinerario se guarda en `localStorage` del navegador.

## Deploy en Vercel

Desde esta carpeta:

```bash
npx vercel
```

O importá el repo en [vercel.com/new](https://vercel.com/new). Framework: Next.js. No hace falta ninguna variable de entorno.
